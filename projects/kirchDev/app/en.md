# The web presence of IT-Dienstleistungen Titus Kirch

The application behind kirch.dev: the site itself, the CV, and this project overview.

## about

kirch.dev is a Laravel application with Vue and Inertia, not a site builder. The CV lives in the code, and the page and the PDF come out of the same build. This project overview pulls its entries in hourly as data, so a new entry needs no deploy.
